## Install

Close the game, unzip the latest [Release](https://github.com/kaelvanzz/HowToFish-helper/releases), run `install.bat`, launch via Steam, press INSERT. Antivirus may flag `winhttp.dll` (injector false positive) — whitelist it. In multiplayer, the host needs this mod too for most features. Uninstall with `uninstall.bat` in the same pack.

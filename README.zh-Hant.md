## 安裝

關遊戲，解壓最新 [Release](https://github.com/kaelvanzz/HowToFish-helper/releases) 裡的 zip，雙擊 `install.bat`，用 Steam 啟動，按 INSERT。防毒可能誤報 `winhttp.dll`（注入器），加白名單即可。連線時大部分功能需要主機也裝本模組。解除安裝用包裡的 `uninstall.bat`。

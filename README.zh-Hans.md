## 安装

关游戏，解压最新 [Release](https://github.com/kaelvanzz/HowToFish-helper/releases) 里的 zip，双击 `install.bat`，用 Steam 启动，按 INSERT。杀软可能误报 `winhttp.dll`（注入器），加白名单即可。联机时大部分功能需要主机也装本模组。卸载用包里的 `uninstall.bat`。
